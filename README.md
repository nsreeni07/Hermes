# Hermes
A 1.7m dual-deployment rocket for both L1 and L2 certification flights, with two redundant flight computers each able to trigger deployment independently. The custom Polaris board also logs data and GPS, with LoRa telemetry in progress for live ground tracking.

I made this project as part of my L1 and L2 certifications and to build my knowledge in rocketry and electronics!
